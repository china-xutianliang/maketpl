# 透明模板制作工具

给 mhxy 第三层做识图模板：连拍同一画面区域 N 张，逐像素比对，
**N 张里都一样的留下，变的（走过的角色、飘动的光效）挖成透明**，输出 RGBA PNG。
工具放副机上跑：直接绑游戏窗口（不走主机连接）。产物可直接进 `resources/nav/templates/`。

## 运行

- 源码：`python main.py`（需要 `pip install -r requirements.txt`）
- 打包：`build.bat` → `dist\透明模板制作.exe`
- 自检：`透明模板制作.exe --selftest`（不弹界面，验证算法，用于确认 exe 能跑）

## 用法

界面分两栏：**左边取图**（绑定 → 框选 → 生成），**右边修图**（预览 → 修图 → 保存），
顶栏有流程指示，不能点的按钮会自动置灰。

1. **绑定窗口**：按住准星拖到游戏窗口上松手（或点"从列表选"），绑定后自动截一张图。
2. **框选区域**：在左侧画面上按住拖动框选要抠的区域（坐标行显示相对/屏幕两套，方向键微移）；
   **单击**一个像素 = 取色，底部状态栏显示颜色描述。右侧实时预览框选内容。
3. 选一条路生成模板：
   - **静态截图**：框选后直接截这块区域一次，进编辑态；也可以**直接点右侧预览**
     进修图。没绑窗口、只"载入图片"时也能用（用载入的图片进编辑）。
   - **动态截图**：实时盯着框选区域，不动的像素留下、动的噪点自动去掉；
     满意后再点一次"停止并生成"。
   - **高级参数**：点左栏底部的"高级参数 ▸"弹出小面板（不重排页面），
     可调抓帧间隔、多帧一致（几张里颜色一样才算稳定像素），
     也能"载入帧文件夹"用已存好的 png/bmp 序列求稳。
4. **修图**（编辑态下预览自动适应窗口，画布上实时显示光标像素的坐标、RGB 和保留/透明状态）：
   - **缩放**：滚轮以鼠标位置为中心放大/缩小；预览右上角的 `−  百分比  +` 也能点，
     点百分比回到"适应"。放大 4 倍以上出像素网格，看得清每个像素。
   - **平移**：放大后按住右键（或中键）拖动画面；点"适应"回到全图。
   - **魔术棒**：修图卡片里有绿色的「✦ 魔术棒」标识，进修图后预览左上角也会出现
     「✦ 魔术棒 · 点画面取色」提示。点一下颜色，选中点击处**连通**的一片（默认；
     可关掉「只选连通」改成全图同色），选中区只画一圈虚线描边，不盖住画面。
     「棒容差」默认 24（游戏截图有噪点，太小会只选到几个像素）；选到的像素少于 16 个时
     状态栏会提示把容差调大。
   - **Shift+点**：继续加选别的颜色，选中区会叠加，弄错了按 Ctrl+Z。
   - **反选透明**：一次把没选中的颜色全部变透明，只留选中的部分（撤销可还原）。
   - **去杂点**：清掉 ≤4 像素的孤立碎块。
   - **裁剪**：编辑态里重新拖框，把图裁到框内（撤销可还原）。
   - **撤销**（或 Ctrl+Z）：退 20 步内的任意一步。
   - **退出**：回到截图框选，框选预览会保留。
5. **保存透明 PNG**（按有效像素外接矩形自动裁边，默认存到 exe 旁的 `out\`；
   有效像素少于 4 个不让存——匹配器要至少 4 个）。
6. **测试匹配**：不离开编辑态，用和 mhxy `find_all` 相同的算法在绑定窗口里找当前模板，
   画面画出命中框和分数（绿=最佳，橙=其余）。分数 ≤ "匹配分数上限"才算中。

## 自检

`透明模板制作.exe --selftest` 核心算法自检；
`--smoke` 真开窗口跑一遍"造帧→单帧→魔术棒选色+反选透明→保存→匹配回找"的完整流程。

## 判定规则

- 每个像素取 N 帧颜色的**中位数**当基准；和中位数每通道差 ≤ 容差的帧算"一致"。
- 一致帧数 ≥ 阈值 → 保留，颜色取中位数；否则 alpha=0。
- 五五分（一半帧是 A 色、一半是 B 色）的像素中位数两边都不沾，会被挖掉——歧义不留，更安全。

## 注意

- 透明信息在 PNG 的 alpha 通道里，普通看图软件会显示成灰白格子或黑底，属正常。
- 保存只允许 PNG（BMP/JPG 会丢透明）。
## 做使者 NPC 模板（给第三层用）

NPC 名字会被别的玩家遮挡，用 NPC 本体做模板更稳。

1. 副机显示缩放必须 **100%**（改完要重启游戏），游戏客户区 **800×600**。
   工具会在绑定/截图时显示"1:1"状态行；不是 1:1 时红字警告，保存前还会再确认一次。
2. 截图前先在游戏里按 **F9 / Alt+H** 屏蔽周边玩家，让 NPC 完整显示。
3. 点"静态截图"。截到的就是框选那一瞬间的画面（所见即所得，不会重抓）。
4. 魔术棒点 NPC 身体颜色（Shift+点加选）→ **反选透明** → **收边 1px**（去掉和背景混色的边）
   → **只留最大块**（去掉散落的背景碎片）。
5. **测试匹配**：默认容差 24、分数上限 10，与 mhxy 第三层 `nav/match.py` 完全一致；
   测试后仍留在修图态，可以接着改。
6. 保存 PNG，放到 `resources/nav/templates/teleport/<地图·NPC>/npc.png`。

保存的 PNG 会写入文字块元数据（工具版本、尺寸、截取原点、客户区、DPI、是否 1:1），便于追查。
载入已有的透明 PNG 会保留 alpha，可以接着修。
